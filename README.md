# 日月潭兩天一夜親子自駕慢活遊 (9/18~9/19)

> 專為夫妻兩人與 **18 個月大女兒**量身打造的南投日月潭慢活假期。兼顧爸爸遠端辦公（古坑星巴克 ＆ 飯店客房）、小女兒午餐後午睡充電、入住後泳池水療、環潭公路兜風美景、第一天老街高評價小吃外帶回房自在享用、第二天退房續玩飯店親子樂園至中午、向山清水模惠蓀輕食漫步消食，以及回程東山服務區親子美味晚餐、即時氣象看板與 GPS 智慧旅行故事！

## 🌤️ 日月潭即時氣象資料看板 (9/18~9/19)

網頁首頁置頂即時氣象看板，出發與打包前一目了然：
- **天氣狀況**：🌤️ 多雲時晴（午後山區局部短暫微陣雨，山區空氣極佳）
- **氣溫預測**：🌡️ **21°C ~ 29°C**（早晚溫差約 8°C，清晨湖面涼爽宜人，建議備妥幼兒防風薄外套）
- **環境濕度**：💧 **72% ~ 75%**（山明水秀、濕度舒適不黏膩）
- **紫外線指數**：☀️ **UV 6 ~ 7（高量級）**（11:00-14:00 戶外陽光強烈，請為小寶寶備妥遮陽帽與嬰幼兒防曬乳）
- **日出日落**：🌅 **日出 05:46** ｜ 🌇 **日落 18:01**（黃昏時段伊達邵水岸夕陽倒影絕美）
- **即時觀測數據**：附交通部中央氣象署 (CWA) 日月潭氣象站即時觀測與雷達回波連結。

## 📌 行程關鍵微調與亮點（符合家庭與 18M 幼兒需求）

1. **第一天去程休息站：雲林古坑服務區（國3 276.9K）**：
   - 爸爸在古坑星巴克享受香濃咖啡、筆電連線專注高效辦公 40 分鐘。
   - 媽媽推著 18M 小女兒漫步戶外「水舞噴泉花園」與「琴聲步道」，草皮放電、呼吸新鮮空氣。
   - 設有高規格獨立冷氣育嬰室，溫奶換尿布便利舒心。

2. **第一天午餐與車上午睡 ＆ 環潭公路兜風**：
   - 中午於「蠻荒咖啡」享用現做義大利麵、法式手工甜點與香醇特調。
   - 午餐後上車，沿著**台21甲環潭景觀公路**放鬆兜風，網頁附有**玄奘寺觀景高點**與**水蛙頭森林水岸彎道**實景美照；18M 女兒在安全汽座上舒適午睡 1 小時充足充電！

3. **第一天下午五星享受 ＆ 晚上無拘束小吃外帶**：
   - 14:45 提早抵達「力麗溫德姆溫泉酒店」辦理入住手續。
   - 下午爸爸在湖景客房安靜辦公；媽媽帶小女兒在 3F 兒童水療戲水池（0.3M 水深）踩水玩樂。
   - 傍晚推車散步至伊達邵碼頭看落日餘暉，並在逐鹿市集欣賞免費邵族歌舞。
   - 晚餐採買伊達邵老街超高評價美食（飯飯雞翅、年記香菇包、阿伯茶葉蛋、清蒸鮮魚豆腐湯、TEA18 紅玉冷泡茶）外帶回飯店客房，夫妻自在享用，18M 小孩無壓力，餐後全家享受客房專屬美人湯溫泉！

4. **第二天上午：取消纜車！退房後親子樂園玩到中午**：
   - 早上悠閒享用溫德姆 1F 饗沐早午餐 Buffet（供餐至 12:00），為小女兒準備細緻白粥、有機蒸地瓜與現煎蛋捲。
   - 取消纜車排隊趕路，10:30 辦理退房行李寄放櫃檯後，**憑房卡/手環繼續留在「RURUZAZA 魯魯札札咖啡親子館」與「3F 兒童戲水池」暢玩至中午 12:00**！巨型球池、溜滑梯、軟墊障礙與積木樂園讓寶寶放電超徹底。

5. **第二天下午：向山清水模輕食漫步（取消集集行程，單純慢活）**：
   - 12:30 前往向山行政暨遊客中心。
   - 剛吃完早餐 Buffet，中午在惠蓀咖啡向山館品嚐輕食午餐（所長茶葉蛋、現烤蜂蜜鬆餅、鮮乳飲品與手沖冰滴咖啡），坐在無邊際水池旁眺望涵碧半島。
   - 推車悠閒漫步「落羽松水上自行車步道」與純白「同心橋」，感受微風與自然湖景。

6. **第二天傍晚回程：台南東山服務區（國3 319K）休息 ＆ 親子晚餐**：
   - 15:30 啟程南下，18M 小女兒在安全汽座上安穩午睡 70-80 分鐘。
   - 16:50 抵達全台佔地最大、綠意盎然的「東山服務區」，觀賞大型水族箱「海底隧道」與戶外百年大榕樹水漾森林。
   - **全家 ＆ 18M 幼兒 3 大東山晚餐推薦**：
     1. **周氏蝦捲 ‧ 鮮魚海產粥 / 現煮鮮魚高湯套餐**：府城國宴名店，高湯鮮甜不油膩，無刺虱目魚肚肉質細嫩，可切碎拌飯餵食寶寶。
     2. **五花馬水餃館 ‧ 手工水餃、蘿蔔糕 ＆ 免費幼兒小米粥**：現包手工高麗菜水餃皮薄餡多，內用提供免費清香小米粥，質地綿密好入口，是 18M 寶寶首選！
     3. **爭鮮迴轉壽司 / 爭鮮 GOGO ‧ 鮮嫩茶碗蒸 ＆ 熟豆皮壽司**：柴魚高湯蒸蛋滑順細緻，香甜熟豆皮壽司乾淨衛生，幼兒接受度極高。

## 🏨 力麗溫德姆溫泉酒店 ‧ 大人與幼童全套設施一覽

- **水療泳池 (3F)**：
  - 戶外兒童戲水池（水深 0.3M，常溫水質，18M 幼兒穿防水泳尿布安全踩水）。
  - 戶外常溫游泳池（標準長度長泳池，成人晨泳與日光浴）。
  - 戶外水療 SPA 池（水深 0.85M，多功能強力水療衝擊泉、氣泡按摩椅，舒緩肩頸腰背）。
  - 日式公共男女裸湯三溫暖（男女獨立美人湯、冷泉池、烤箱、蒸氣室，限成人放鬆）。
- **親子放電樂園**：
  - RURUZAZA 魯魯札札咖啡親子館（飯店特約，步行僅 50 公尺，房客退房當日中午前仍可憑證免費暢玩數百坪巨型球池、幼兒爬行區、溜滑梯與積木城堡）。
- **成人休閒舒壓**：
  - 3F 專業健身中心（智能跑步機、飛輪划船機、專業啞鈴組，06:00–22:00）。
  - 3F SUI 水溫泉芳療 SPA（頂級精油芳療按摩，預約制媽媽尊寵護理）。
  - 頂樓 The Moon 月光酒吧（入夜後眺望水岸夜景與星空特調）。
- **客房專屬私密設施 ＆ 幼童備品**：
  - 每房專屬大理石造美人湯雙浴池（碳酸氫鈉泉無硫磺刺鼻味，溫和親膚，水溫精準自由調節）。
  - 爸爸遠端辦公專用硬體（獨立書桌、全區高速 Wi-Fi、膠囊咖啡機、外推景觀陽台）。
  - 18M 幼兒專屬五星備品（預約提供：嬰兒床、紫外線消毒鍋、溫奶器、澡盆水杓組、小鴨沐浴組）。
- **星級餐飲服務**：
  - 1F 饗沐全日早午餐 Buffet（供餐至 12:00，寶寶細粥、現煮牛肉湯、高腳椅）。
  - 月影鐵板燒、粵菜中餐廳、大吉酒吧。
