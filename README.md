# 日月潭兩天一夜親子自駕慢活遊 (9/18~9/19)

> 專為夫妻兩人與 17 個月大女兒量身打造的南投日月潭慢活假期。兼顧爸爸遠端辦公（東山星巴克 ＆ 飯店房間辦公）、小女兒午餐後午睡充電、入住後直接衝溫德姆泳池放電、避開向山微波雷餐改享蠻荒現做義麵、惠蓀咖啡景觀第一排品茶葉蛋、**第一天晚上老街步行高評價小吃外帶回客房自在享用（零壓力免受餐廳拘束）**、**官方推薦向山水上落羽松同心橋 ＆ 伊達邵逐鹿市集邵族歌舞**，以及**旅行照片上傳與 GPS 智慧旅行故事**全收錄！

## 📌 行程關鍵微調與亮點（符合家庭與幼兒需求）
1. **官方推薦精選新增行程（100% 嬰兒推車友善 ＆ 幼兒放電）**：
   - **向山水上落羽松步道 ＆ 永結同心橋（Day 1 14:15 - 14:45）**：
     CNN 評選全球十大最美自行車道精華段！全平緩無階梯木棧道，推車漫步於綠蔭落羽松與碧綠湖水間，微風徐徐，正是 17M 寶貝舒服小睡的黃金時段；同心橋純白弧形橋身與湖面倒影更是全家美拍勝地！
   - **伊達邵碼頭水岸夕陽 ＆ 逐鹿市集邵族杵音歌舞（Day 1 17:30 - 18:00）**：
     飯店下樓步行 2 分鐘直達伊達邵親水平台，推推車看夕陽晚霞染紅湖水；在逐鹿市集廣場免費欣賞邵族傳統杵音與迎賓歌舞，歡樂節奏讓 17M 寶寶開懷拍手同樂！
2. **第一天晚餐：老街步行高評價小吃外帶回客房大餐**：
   - 考量 17 個月大幼兒在餐廳容易坐不住、搶餐具或哭鬧，改為**下樓步行 1~3 分鐘**快速採買伊達邵最高評價小吃外帶回飯店房內享用：
     - **麓司岸 飯飯雞翅** (Google 4.3★，2,500+則)：五星主廚阿聖師名作，去骨雞翅塞滿邵族糯米飯！
     - **年記做不復賣香菇高麗菜包** (Google 4.3★，4,000+則)：外皮金黃酥脆、高麗菜香菇內餡多汁！
     - **杰記山豬肉大刈包 / 香腸** (Google 4.2★，1,200+則)：南瓜餅皮現烤山豬肉。
     - **富園餐館 / 麓司岸** (Google 4.6★)：外帶一份清蒸無刺鮮鱸魚湯、炒高麗菜與白飯，給 17M 女兒少鹽健康的現做熱食！
     - **TEA18 朝霧紅茶** (Google 4.5★，2,000+則)：有機冷泡紅玉紅茶甘甜解膩。
     - **杜咪米糬** (Google 4.7★)：邵族現烤手工小米麻糬當甜點。
   - 回飯店客房在寬敞舒適環境下自在用餐，寶寶開心無拘束，爸媽零壓力！
3. **📸 旅行照片上傳 ＆ GPS 智慧「旅行故事」回憶錄**：
   - **純前端安全解析**：透過 exifr 在瀏覽器本地讀取照片 EXIF 中的 GPS 經緯度與拍攝時間，照片留存本機記憶體，完全不經由第三方伺服器，100% 保障家人與小孩隱私。
   - **智慧比對景點**：利用 Haversine 演算法自動將照片 GPS 定位與行程景點進行空間比對（支援東山服務區、蠻荒咖啡、向山、同心橋、溫德姆、伊達邵碼頭/老街、纜車、土角厝、妮娜城堡等），若無 GPS 則以時間自動匹配。
   - **三大故事組合切換**：
     - ⏰ **依時間軸故事**：呈現兩天一夜垂直時光手帳，順時重溫美好歷程。
     - 📍 **依行程景點故事**：依景點分組回顧各站亮點與照片。
     - 👨‍👩‍👧 **依人物主角故事**：聚焦「👧 小寶貝 17M 成長冒險」、「👨 爸爸行動辦公」、「👩 媽媽美拍放鬆」或「👨‍👩‍👧 全家福甜蜜時光」。
   - **AI 動態旅行日記生成 ＆ 地圖連動**：依據選取的組合自動生成暖心旅行日記，可一鍵複製文字分享；並在 Leaflet 導航地圖上即時繪製「📷 照片足跡打卡點」！
   - **內建示範相簿 (Demo)**：點擊「載入示範照片」即可在出發前搶先體驗所有組合與地圖連動功能。
4. **爸爸專屬遠端辦公**：
   - 去程在**東山服務區星巴克**（插座、高速網路）專注辦公 1 小時。
   - 下午入住力麗溫德姆後，在寬敞客房（高速 Wi-Fi、辦公書桌）安靜上班。
5. **女兒午睡與泳池時段**：
   - 17 個月女兒在午餐後（向山漫步與車程中）即先午睡充電 1 小時。
   - Check-in 入住後精神飽滿，由媽媽帶著直接前往飯店 3F **戶外水療池與兒童戲水池**（或 RURUZAZA 魯魯札札親子館）盡情玩水放電！
6. **第一天午餐替代方案 ＆ 惠蓀咖啡賞景攻略**：
   - 避開向山惠蓀咖啡被詬病的微波主餐與過甜茶凍，午餐改至台21線最美白色景觀餐廳「**蠻荒咖啡**」享用主廚現點現做義大利麵、燉飯與舒肥沙拉。
   - 隨後前往向山行政遊客中心漫步清水模，並到**台灣惠蓀咖啡向山館**「專注品嚐手沖咖啡、所長茶葉蛋（網友公認必吃！）與冰淇淋」，飽覽無邊際水池與湖景第一排！
7. **全景點實景照片收錄**：
   - 網頁上每個行程與站點皆嵌入對應實景參考照片，未做功課也能秒懂亮點！
