# 日月潭兩天一夜親子自駕慢活遊 (9/18~9/19)

> 專為夫妻兩人與 **18 個月大女兒**量身打造的南投日月潭慢活假期。兼顧爸爸遠端辦公（東山星巴克 ＆ 飯店房間辦公）、小女兒午餐後午睡充電、入住後直接衝溫德姆泳池放電、避開微波主餐改享蠻荒現做義麵、第二天退房後悠遊向山品嚐惠蓀輕食午餐、回程順遊**集集「保育教育館」室內野生動物生態劇場**、**第一天晚上老街步行高評價小吃外帶回客房自在享用（零壓力免受餐廳拘束）**、**官方推薦伊達邵逐鹿市集邵族歌舞 ＆ 向山落羽松水上步道**，以及**旅行照片上傳與 GPS 智慧旅行故事**全收錄！

## 📌 行程關鍵微調與亮點（符合家庭與 18M 幼兒需求）

1. **第一天減負慢活 ＆ 專注享受五星飯店設施**：
   - **向山移至第二天**：第一天午餐在「蠻荒咖啡」吃飽後，車程讓 18M 女兒在安全汽座上舒適午睡 1 小時，14:45 提早前往力麗溫德姆辦理入住手續，節奏完全不緊湊！
   - **下午工作與放電雙軌兼顧**：爸爸在景觀客房安靜遠端工作；媽媽帶充飽電的小女兒前往 3F **兒童戲水池（水深 0.3M）**踩水嬉戲，或至步行 50 公尺特約的**「RURUZAZA 魯魯札札咖啡親子館」**暢玩巨型球池！
   - **傍晚伊達邵水岸夕陽 ＆ 邵族歌舞**：全家推著推車下樓步行 2 分鐘直達碼頭親水平台看晚霞倒影，並在逐鹿市集廣場免費欣賞邵族傳統杵音與迎賓歌舞。
   - **第一天晚餐：老街步行高評價小吃外帶回客房**：
     - 下樓 1~3 分鐘採買排隊名店（飯飯雞翅、年記香菇高麗菜包、清蒸鮮魚豆腐湯、TEA18 紅玉冷泡茶）。
     - 回飯店客房在寬敞舒適環境下自在用餐，18M 寶寶坐得舒服、爸媽零壓力，餐後全家享受客房專屬美人湯！

2. **第二天重構：湖景纜車 ➔ 向山輕食漫步 ➔ 集集全室內生態生態館**：
   - **溫德姆 1F 饗沐早午餐 Buffet（供餐至 12:00！）**：早午餐規格免趕早，提供寶寶細緻白粥、有機蒸地瓜與現煎蛋捲。
   - **日月潭高空纜車（伊達邵站）**：全站無障礙電梯，俯瞰 360 度米其林三星湖景。
   - **向山行政遊客中心 ‧ 惠蓀咖啡輕食午餐（12:00 - 13:30）**：
     - 剛吃過早餐 Buffet，中午在惠蓀向山館簡單品嚐「所長茶葉蛋（香濃入味、幼兒愛吃蛋黃）、現烤蜂蜜鬆餅、鮮乳飲品與手沖/冷萃冰滴咖啡」，坐在第一排落地窗前看無邊際水池。
     - 順著清水模緩坡漫步至「落羽松水上自行車步道」與純白「同心橋」，吹著微風推車散步消食。
   - **集集 ‧ 農業部生物多樣性研究所「保育教育館」（13:45 - 15:30）**：
     - **全室內冷氣避暑**：100% 全室內空調，午後避開炎熱豔陽與戶外蚊蟲。
     - **推車全無障礙電梯**：全館 3 層樓（B1~2F）無障礙通道平緩順暢，配有獨立五星級哺集乳室。
     - **18 個月大幼兒最愛**：展出 1:1 等身大擬真台灣黑熊、石虎、穿山甲、台灣獼猴模型與森林鳥叫聲音效，小寶寶看到大動物興奮度破表！
     - **超高 CP 值**：大人門票僅 $60 元、未滿 6 歲幼兒免費入場。
     - **順路回程動線**：參觀完 15:45 直接由集集上國道3號名間/竹山交流道南下，寶寶在汽座上剛好安穩午睡 45~60 分鐘，無縫銜接古坑服務區！

3. **🏨 力麗溫德姆溫泉酒店 ‧ 大人與幼童全套休閒設施一覽**：
   - **水療泳池 (3F)**：
     - 戶外兒童戲水池（水深 0.3M，常溫水質，18M 幼兒穿防水泳尿布安全踩水）。
     - 戶外常溫游泳池（標準長度長泳池，成人晨泳與日光浴）。
     - 戶外水療 SPA 池（水深 0.85M，多功能強力水療衝擊泉、氣泡按摩椅，舒緩肩頸腰背）。
     - 日式公共男女裸湯三溫暖（男女獨立美人湯、冷泉池、烤箱、蒸氣室，限成人放鬆）。
   - **親子放電樂園**：
     - RURUZAZA 魯魯札札咖啡親子館（飯店特約，步行僅 50 公尺，房客憑房卡免費暢玩數百坪巨型球池、幼兒爬行區、溜滑梯與積木城堡）。
   - **成人休閒舒壓**：
     - 3F 專業健身中心（智能跑步機、飛輪划船機、專業啞鈴組，06:00–22:00）。
     - 3F SUI 水溫泉芳療 SPA（頂級精油芳療按摩，預約制媽媽尊寵護理）。
     - 頂樓 The Moon 月光酒吧（入夜後眺望水岸夜景與星空特調）。
   - **客房專屬私密設施 ＆ 幼童備品**：
     - 每房專屬大理石造美人湯雙浴池（碳酸氫鈉泉無硫磺刺鼻味，溫和親膚，水溫精準自由調節）。
     - 爸爸遠端辦公專用硬體（獨立書桌、全區高速 Wi-Fi、膠囊咖啡機、外推景觀陽台）。
     - 18M 幼兒專屬五星備品（預約提供：嬰兒床、紫外線消毒鍋、溫奶器、澡盆水杓組、小鴨沐浴組）。
   - **星級餐飲服務**：
     - 1F 饗沐全日早午餐 Buffet（供餐至 12:00，寶寶細粥、現煮牛肉湯、高腳椅）。
     - 月影鐵板燒、粵菜中餐廳、大吉酒吧。
