# 日月潭兩天一夜親子自駕慢活遊 (9/18~9/19)

> 專為夫妻兩人與 17 個月大女兒量身打造的南投日月潭慢活假期。兼顧爸爸遠端辦公（東山星巴克 ＆ 飯店房間辦公）、小女兒午餐後午睡充電、入住後直接衝溫德姆泳池放電、避開向山微波雷餐改享蠻荒現做義麵、惠蓀咖啡景觀第一排品茶葉蛋、第一天高評價邵族創意手創晚餐，以及各景點精選照片全收錄！

## 📌 行程關鍵微調與亮點（符合家庭需求）
1. **爸爸專屬遠端辦公**：
   - 去程在**東山服務區星巴克**（插座、高速網路）專注辦公 1 小時。
   - 下午入住力麗溫德姆後，在寬敞客房（高速 Wi-Fi、辦公書桌）安靜上班。
2. **女兒午睡與泳池時段**：
   - 17 個月女兒在午餐後（向山漫步與車程中）即先午睡充電 1 小時。
   - Check-in 入住後精神飽滿，由媽媽帶著直接前往飯店 3F **戶外水療池與兒童戲水池**（或 RURUZAZA 魯魯札札親子館）盡情玩水放電！
3. **第一天午餐替代方案 ＆ 惠蓀咖啡賞景攻略**：
   - 避開向山惠蓀咖啡被詬病的微波主餐與過甜茶凍，午餐改至台21線最美白色景觀餐廳「**蠻荒咖啡**」享用主廚現點現做義大利麵、燉飯與舒肥沙拉。
   - 隨後前往向山行政遊客中心漫步清水模，並到**台灣惠蓀咖啡向山館**「專注品嚐手沖咖啡、所長茶葉蛋（網友公認必吃！）與冰淇淋」，飽覽無邊際水池與湖景第一排！
4. **第一天高評價精緻晚餐（開車15分鐘內）**：
   - 首選推薦：**麓司岸手創料理餐坊**（Google 4.6★ 2,800+好評，伊達邵文化街，車程1分鐘），五星主廚阿聖師邵族創意合菜（陶板山豬肉、清蒸鱸魚、得獎炸香蕉「蕉蕉者」）。
   - 秘境備選：**一味無二 綠食坊**（Google 4.4★ 1,200+好評，車程12分鐘），日式禪風無毒養生套餐，環境清幽大草皮。
5. **全景點實景照片收錄**：
   - 網頁上每個行程與站點皆嵌入對應實景參考照片，未做功課也能秒懂亮點！
