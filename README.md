# 日月潭兩天一夜親子自駕慢活遊 (9/18~9/19)

> 專為夫妻兩人與 17 個月大女兒量身打造的南投日月潭慢活假期。包含高雄自駕路線、國道五星服務區中繼站、力麗溫德姆溫泉酒店住宿攻略、100% 嬰兒推車友善景點、伊達邵在地排隊美食、17M 幼兒出行打包檢核表，以及一鍵喚醒 Google Maps 的行車路線導航。

## 📌 行程基本資訊
- **旅行日期**：2026/09/18 (五) ~ 09/19 (六) (兩天一夜)
- **家庭成員**：夫妻 2 人 + 17 個月大女兒
- **交通方式**：自駕（高雄 ↔ 日月潭）
- **住宿飯店**：[力麗溫德姆溫泉酒店](https://wyndhamsunmoonlake.com/)（伊達邵碼頭旁，客房獨立溫泉美人湯）
- **節奏設定**：定點慢活、推車無障礙、定時回房午睡與泡湯、避開趕路

## 🗺️ 兩天一夜精華行程

### Day 1 (9/18 星期五)：湖畔慢活 ‧ 溫泉舒享之旅
- **早上**：
  - 08:30 高雄出發（國道10號 ➔ 國道3號北上）
  - 09:45 - 10:30 **【國道休息站】東山服務區 (國3 319K)**：全台唯一海底隧道大水族箱看魚放電、五星哺集乳室換尿布
  - 11:45 - 14:00 **向山行政暨遊客中心 ＆ 惠蓀咖啡向山館**：團紀彥清水模建築、懸臂觀景步道、100% 推車無障礙、景觀午餐
- **下午**：
  - 14:30 - 15:30 **力麗溫德姆溫泉酒店 Check-in**（伊達邵商圈核心）
  - 15:00 - 16:15 寶寶回客房午睡充電（避免傍晚哭鬧，爸媽喝咖啡看山景）
  - 16:30 - 17:45 **RURUZAZA 魯魯札札咖啡親子館**（房客免費暢玩球池溜滑梯積木）或飯店 3F 親子戲水池
- **晚上**：
  - 18:00 - 20:00 **伊達邵老街商圈漫步 ＆ 水岸夜景**：飯店下樓步行 2 分鐘，年記高麗菜包、麓司段山豬肉香腸、杰記大刈包、TEA18 朝霧紅茶，或富園餐館邵族合菜
  - 20:30 - 22:00 **客房專屬美人湯**：碳酸氫鈉泉清澈無硫磺味，溫和親膚，安撫寶寶入睡後夫妻私密泡湯放鬆

### Day 2 (9/19 星期六)：全景纜車 ‧ 夢幻城堡與甜蜜賦歸
- **早上**：
  - 08:00 - 09:45 **溫德姆 1F 饗沐全日自助餐廳**：超狂供應至中午 12:00（早午餐規格免趕早），幼童餐椅餐具、地瓜白粥鮮奶水果
  - 10:00 - 11:30 **日月潭纜車（伊達邵站）**：未滿 3 歲幼童免票，推車可折疊進車廂，俯瞰米其林三星 360 度湖景
- **下午**：
  - 11:45 飯店退房 Check-out
  - 12:15 - 13:30 **土角厝水上庭園旋轉餐廳（埔里桃米）**：全台唯一水上旋轉包廂、餵錦鯉看魚、清爽健康少鹽台菜
  - 13:45 - 15:30 **Cona's 妮娜巧克力夢想城堡**：全室內冷氣電梯推車友善、免費宮廷禮服全家變裝拍照、互動換巧克力遊戲、採買世界金牌生巧克力伴手禮
- **晚上**：
  - 15:30 國道 6 號愛蘭交流道接國道 3 號南下（寶寶車上午睡充電）
  - 16:30 - 17:15 **【國道休息站】古坑服務區 (國3 276K)**：水舞音樂花園、古坑手沖咖啡提神、五星哺集乳室換尿布與喝水
  - 18:45 - 19:15 平安返抵高雄溫暖的家
